# Harness

열어 둔 사이트 밖으로 끌려 나가지 않게 막아 주는 SwiftUI + WebKit 브라우저.
광고 오버레이 클릭 · 강제 리다이렉트 · 팝업 · 앱 스킴 호출을 차단하고, 필요한 것만 골라 허용한다.

## 기능

### 차단
- **사이트 고정** — 주소창에서 연 사이트(등록 도메인 기준)로 탭을 고정하고, 다른 사이트로의 이동을 막는다
- **팝업 차단** — `window.open` · `target=_blank` 는 막는다. 같은 사이트 링크를 직접 누른 경우만 새 탭으로 연다
- **외부 앱 호출 차단** — `itms-apps:` · `intent:` 등 http(s) 이외의 스킴
- **외부 스크립트 차단** — 다른 도메인에서 불러오는 스크립트를 `WKContentRuleList` 로 막는다
- 차단되면 하단 배너로 알리고, 그 자리에서 **허용**하거나 새 탭으로 열 수 있다

### 사이트별 규칙
- 방패 메뉴에서 사이트마다 JavaScript · 외부 스크립트 설정을 따로 지정
- 허용한 이동 대상은 저장되어 다음 방문에도 적용된다

### 탭 · 보관함
- 창(세션)별로 열린 탭을 저장하고 복원
- 탭 목록 카드 화면 (탭하면 전환, 옆으로 밀면 닫기)
- 북마크 — 그룹으로 정리, 길게 눌러 그룹 이동
- 방문 기록 (90일) · 차단 통계 (30일)

### 화면
- iOS 에서 아래로 스크롤하면 탭 줄 · 주소창을 숨기고, 위로 올리면 다시 표시
- 한국어 · 영어 · 일본어

## 차단 기능 상세

주소창 오른쪽 **방패 버튼**에서 켜고 끈다. 위의 세 가지는 전체 설정, 아래의 사이트별 규칙은 지금 사이트에만 적용된다.

| 설정 | 기본값 | 바꿀 수 있나 |
|---|---|---|
| 다른 사이트로 이동 차단 | 켬 | 전체 |
| 외부 스크립트 차단 | 켬 | 전체 · 사이트별 |
| JavaScript 허용 | 켬 | 전체 · 사이트별 |
| 팝업 차단 | 항상 | — |
| 외부 앱 호출 차단 | 항상 | — |

### 다른 사이트로 이동 차단

주소창에서 직접 연 사이트로 탭을 고정하고, 메인 화면이 **다른 등록 도메인**으로 넘어가는 것을 막는다.
`www.example.co.kr` 과 `m.example.co.kr` 은 같은 사이트로 본다.

막을 수 있는 것
- 본문 위에 깔린 투명 광고를 잘못 눌러 도박 · 쇼핑 사이트로 넘어가는 것
- 페이지를 열자마자 스크립트(`location.href = …`)나 `<meta http-equiv="refresh">` 로 다른 곳에 보내는 것
- 서버 리다이렉트(302)로 낯선 도메인을 거쳐 가는 것
- 단축 URL · 추적 링크를 통한 우회 이동

알아 둘 점
- iframe 안의 이동은 막지 않는다 (화면을 빼앗지 않으므로)
- 뒤로 · 앞으로 가기는 막지 않는다
- 정상적인 외부 이동(예: `accounts.google.com` 소셜 로그인, 결제 페이지)도 걸린다.
  배너의 **허용**을 누르면 그 대상 도메인이 이 사이트의 허용 목록에 저장되어 다음부터는 통과한다

### 팝업 차단 (항상)

`window.open` 과 `target="_blank"` 로 새 창을 띄우는 것을 막는다.

막을 수 있는 것
- 아무 곳이나 누르면 뒤에서 광고 창이 열리는 클릭 언더(pop-under)
- 페이지를 열거나 닫을 때 자동으로 뜨는 창
- 다운로드 버튼처럼 꾸민 광고 링크가 새 창으로 열리는 것

같은 사이트의 링크를 **사용자가 직접 누른** 경우만 새 탭으로 연다. 막힌 팝업은 차단 기록에서 이 탭이나 새 탭으로 열 수 있다.

### 외부 앱 호출 차단 (항상)

`http` · `https` 이외의 주소(앱 스킴)로의 이동을 막는다. 앱 안에서 열 수 없으므로 허용 버튼이 없다.

막을 수 있는 것
- `itms-apps://` 로 App Store 가 갑자기 열리는 것
- `intent://` · `kakaotalk://` 등으로 다른 앱이 실행되는 것

`tel:` · `mailto:` 링크도 같이 막힌다.

### 외부 스크립트 차단

페이지와 **다른 도메인에서 불러오는 스크립트**를 받지 않는다. 같은 사이트의 스크립트는 그대로 실행된다.
설정을 바꾸면 페이지를 다시 불러와 적용한다.

막을 수 있는 것
- 광고 네트워크 스크립트 (배너 · 전면 광고 · 광고 오버레이)
- 방문 추적 · 분석 스크립트
- 광고 스크립트가 심어 두는 리다이렉트 · 팝업 코드

부작용
- 외부 CDN(cdnjs · jsDelivr 등)에서 라이브러리를 받아 쓰는 사이트는 메뉴나 버튼이 동작하지 않을 수 있다
- 다른 사이트의 기능을 끼워 넣은 부분 — 유튜브 플레이어, 댓글 위젯, reCAPTCHA, 결제창 — 이 깨질 수 있다

이럴 때는 방패 메뉴의 **이 사이트 › 외부 스크립트 › 허용** 으로 그 사이트만 풀어 준다.

### JavaScript 허용

끄면 그 페이지의 스크립트를 **전부**(같은 사이트 것 포함) 실행하지 않는다. 외부 스크립트 차단보다 훨씬 강하다.

끄면 막을 수 있는 것
- 스크립트로 하는 모든 자동 이동 · 팝업 · 무한 경고창(`alert`)
- 스크롤을 가로채거나 뒤로 가기를 막는 동작
- 일부 사이트의 "광고 차단을 꺼 주세요" 가림막, 자동 재생 영상

부작용
- 화면을 스크립트로 그리는 사이트(SPA)는 빈 화면이 된다
- 로그인 · 검색 · 메뉴 펼치기 등 대부분의 버튼이 동작하지 않는다

글만 읽으면 되는 뉴스 · 블로그 · 커뮤니티에서 사이트별로 끄는 용도에 맞다.
서버 리다이렉트와 `<meta refresh>` 는 스크립트가 아니므로 이 설정과 상관없이 일어난다 — 다른 사이트로 가는 것은 **이동 차단**이 막는다.

### 사이트별 규칙

방패 메뉴의 **이 사이트 (도메인)** 에서 JavaScript · 외부 스크립트를 `전체 설정 따름 / 허용 / 차단` 중에 고른다.
사이트별 값이 있으면 전체 설정보다 우선한다. 저장된 규칙은 **보관함 › 사이트** 에서 확인하고 지운다.

### 상황별 예

| 상황 | 설정 |
|---|---|
| 웹툰 · 스트리밍 사이트에서 누를 때마다 광고 창이 뜨고 다른 사이트로 넘어간다 | 기본값 그대로 (이동 차단 + 외부 스크립트 차단 + 팝업 차단) |
| 그래도 같은 사이트의 스크립트가 경고창을 띄우거나 뒤로 가기를 막는다 | 이 사이트만 JavaScript **차단** |
| 영상 · 댓글 · 로그인 버튼이 안 눌린다 | 이 사이트만 외부 스크립트 **허용** |
| 소셜 로그인 · 결제로 넘어가야 한다 | 차단 배너에서 **허용** (대상 도메인이 저장됨) |
| 링크를 따라 여러 사이트를 자유롭게 돌아다니고 싶다 | 다른 사이트로 이동 차단 **끄기** |

## 빌드

```bash
open Harness.xcodeproj
```

스킴 `Harness` 를 선택해 실행한다. 번들 ID 는 `com.satokim.harness`.

## 구조

```
Harness/
├── HarnessApp.swift          앱 진입점 (SwiftData 컨테이너)
├── ContentView.swift         창 · 탭 줄 · 시트 배치
├── Localizable.xcstrings     다국어 문자열 (ko · en · ja)
└── Browser/
    ├── BrowserTab.swift      탭 하나 = WKWebView 하나. 이동 · 팝업 제어
    ├── BrowserStore.swift    탭 목록 · 저장 · 차단 설정 · 콘텐츠 규칙
    ├── BrowserModels.swift   SwiftData 모델 (사이트 규칙 · 탭 · 북마크 · 기록 · 차단 기록)
    ├── BrowserViews.swift    주소창 · 배너 · 방패 메뉴
    ├── BookmarkEditorView.swift  북마크 추가 · 편집
    ├── LibraryView.swift     보관함 (북마크 · 기록 · 차단 · 사이트)
    └── TabOverviewView.swift 탭 목록 카드
```
